# ADR 005 — 로컬 LLM: 카드 문장 다듬기 + 내 데이터에 묻기(text-to-SQL)

- 상태: 채택 (2026-10-11)
- 맥락: 규칙 엔진 카드는 정확하지만 문장이 딱딱하다 ("탑에서 골반이 오른쪽으로 밀렸어요 (기준 스윙보다 공 2개 정도)").
  누적 분석 탭은 미리 만든 차트만 보여 줘서 "9월 드라이버 슬라이스 몇 번?" 같은 질문은 SQL을 직접 써야 했다.
  외부 API 없이 데스크탑(RTX 3060 12GB)에서 돌아야 한다.

## 결정

```
카드:  규칙 엔진 → (무엇을 말할지 확정) → Qwen3 8B가 말투만 수정 → 검사 통과 시만 교체, 아니면 규칙 문장 유지
질문:  LangGraph  generate → validate → execute → answer   (실패 시 이유를 붙여 다시 생성, 최대 3회)
```

| 결정 | 이유 |
|---|---|
| Ollama + Qwen3 8B (Q4, 생각 모드 끔) | VRAM 약 6GB로 GPU에 전부 올라감. 한국어 품질과 JSON 스키마 출력 지원. 카드 1장 약 1.9초, 질문 1개 약 1.5초 |
| LLM은 **어떻게 말할지만**, 무엇을 말할지는 규칙 | 진단이 바뀌면 코칭이 틀린다. 숫자·비교 기준이 바뀐 출력은 버리고 규칙 문장을 그대로 씀 |
| 다듬기 검사: 한국어만 · 숫자 동일 · "기준 스윙"/"평소 좋은 샷" 유지 · 길이 1.6배 이내, 위반 시 이유를 알려 1회 재시도 | 아래 "겪은 문제" 참고 |
| SQL 검사: SELECT/WITH 한 문장, DDL·DML 금지, `lakehouse.gold.*` / `lakehouse.silver.*`만, LIMIT 강제 | 모델이 무엇을 만들든 읽기 전용. "테이블 다 지워줘" → DELETE 생성 3회 모두 차단 후 포기 |
| 답변 숫자 검사: 답에 나온 숫자는 결과 행에 있어야 함, 아니면 표 요약으로 대체 | 그럴듯한 숫자 지어내기 방지 |
| 의미 규칙(질문 유형 → 테이블)과 예시 4개는 평가셋과 다른 질문 | 평가셋을 프롬프트에 넣으면 점수가 의미 없음 |
| `seed` 고정 + 평가는 3회 반복 | 온도 0이어도 실행마다 11~13/15로 흔들렸음 |
| Ollama가 꺼져 있으면 규칙 경로로 동작 | LLM은 선택 기능. 앱·파이프라인은 그대로 |

## 검증 (2026-10-11)

| 항목 | 결과 | 방법 |
|---|---|---|
| 카드 다듬기 채택률 | 25/30 (83%), 거절 5건은 모두 비교 기준 표현 누락 → 규칙 문장 유지 | `scripts/eval_polish.py` |
| text-to-SQL 실행 정확도 | 스키마만 8/15 (53%) → 의미 규칙 12/15 (80%), seed 고정 3회 모두 12/15 | `scripts/eval_ask.py --repeat 3`, 정답 SQL과 결과 비교 |
| 위험한 질문 | DELETE 3회 생성 → 3회 모두 검사에서 차단 | `/api/ask` 수동 확인 |
| 가드 단위 테스트 | 10개 (다듬기 6, SQL·답변 4) | `pytest` |

남은 오답 3개: 비율의 분모(구질 라벨 있는 샷만), 두 테이블 조인(템포), 날짜 문자열 조건.
의미 규칙을 이 평가셋을 보면서 다듬었으므로 처음 보는 질문에서는 더 낮을 것이다. 별도 검증용 질문셋이 다음 단계.

## 겪은 문제

- **숫자는 다 맞는데 일본어**: 첫 버전은 숫자 검사만 해서 100% 통과했는데, 출력을 읽어 보니 일본어였다 → 한글 포함·가나/한자 금지 검사, 시스템 프롬프트를 한국어로.
- **비교 기준이 사라짐**: "기준 스윙보다 공 2개" → "공 2개 정도 밀렸어요". 숫자는 같지만 무엇과 비교했는지가 사라져 뜻이 바뀐다. 검사를 넣자 채택률 28% → 규칙 명시 + 예시 2개 + 위반 이유를 알려 주는 재시도 1회로 83%.
- **규칙을 더하면 오히려 떨어짐**: 남은 오답을 겨냥한 규칙 하나("전체 비율은 round_summary로 답하지 말 것")를 넣자 13/15 → 12/15. 모델이 무시하고 다른 질문을 틀렸다 → 되돌림.
- **같은 프롬프트, 다른 점수**: 온도 0인데도 11/15, 13/15가 번갈아 나옴 → seed 고정, 평가 3회 반복 후 보고. 한 번 잘 나온 점수를 보고하지 않는다.
